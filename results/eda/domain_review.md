### 1.2 `-newstructure`의 의미

원저자 `batch_analysis.m`은 Arbin metadata의 `schedule_file` 이름에서 `charging_algorithm`을 얻는다. `cell_analysis.m`은 그 문자열의 `(NEWSTRUCTURE`를 `-newstructure`로 치환해 `policy_readable`을 만든다. [스케줄 이름 추출](https://github.com/chueh-ermon/BMS-autoanalysis/blob/c82ab7704211a6aee75bd926714b82d1f95e1a0e/batch_analysis.m), [정책 문자열 변환](https://github.com/chueh-ermon/BMS-autoanalysis/blob/c82ab7704211a6aee75bd926714b82d1f95e1a0e/cell_analysis.m)

확인 가능한 의미는 **스케줄 식별자에 포함된 문자열**까지다. 구체적으로 어떤 스케줄이 바뀌었는지, 셀의 화학계·전극·물리적 구조가 바뀌었는지, MAT schema가 바뀌었는지는 이 접미사로 확정할 수 없다. 원문 `policy_readable`은 보존하고, C1·Q1·C2를 파싱하더라도 접미사를 별도 필드로 남기는 것이 적절하다. 동일한 파싱 결과만으로 서로 다른 날짜의 실제 시험 조건이 같다고 선언하지 않는다.

### 1.3 충전 정책의 해석

표준 `C1(Q1%)-C2`는 **0→Q1%에 C1, Q1→80%에 C2**를 적용하는 정책이다. 표준 예측 코호트에서 80→100%는 공통 1C CC-CV 충전이며, C2가 마지막 20%에 적용되는 것은 아니다. 예를 들어 `5.4C(80%)-5.4C`는 0→80% 구간의 단일 5.4C 충전에 해당한다. [원 논문 Methods](https://web.mit.edu/braatzgroup/Severson_NatureEnergy_2019.pdf), [Supplementary Table 9](https://media.springernature.com/original/springer-static/esm/art%3A10.1038%2Fs41560-019-0356-8/MediaObjects/41560_2019_356_MOESM1_ESM.pdf)

따라서 최고 C-rate 하나보다 적용 SOC 구간·전환점·실제 파형을 함께 비교해야 한다. 표준 구간을 이상적인 일정 전류로만 계산한 80% 도달 시간은 `60 × [q1/C1 + (0.8−q1)/C2]`분이다(`q1=Q1/100`). 실제 시간에는 휴지·제어·측정 영향이 있으므로 이는 설명용 계산이다. 진단·저율·변형 스케줄에는 실제 파형을 확인하기 전에 일반 정책식을 무조건 적용하지 않는다.

## 2. 수명 라벨·EOL·관측 종료의 구분

원 논문의 공칭 용량은 1.1Ah이며, 공칭 용량의 80%를 기준으로 하면 EOL 용량은 **0.88Ah**다. 이 기준은 초기 관측 평균의 80%와 다르다. 현장 ESS의 교체 결정을 일률적으로 0.88Ah 또는 이 실험의 사이클 수로 옮기는 것도 적절하지 않다. [원 논문](https://web.mit.edu/braatzgroup/Severson_NatureEnergy_2019.pdf)

로컬 `barcode`·`channel_id`는 MATLAB string의 opaque 직렬화 값으로 보이는 uint32 배열이며, 평문 바코드가 아니다. 저장 배열의 정수·참조 위치를 문자열로 변환하거나 파일 간 동일한 정수 패턴을 비교해 물리적 셀 동일성을 판정하면 안 된다. 공식 Python 변환 자료에도 바코드·채널은 제공되지 않는다고 명시되어 있다. ## 3. Qdlin 전압축과 ΔQ(V) 특징

### 3.1 로컬 전압축·단위 확인

세 파일 모두 최상위 키는 `#refs#`, `#subsystem#`, `batch`, `batch_date`이며 **최상위 `V`는 없다.** 139셀 모두의 `batch.Vdlin`은 1,000점, **3.5→2.0V 내림차순**이다. `linspace(3.5,2.0,1000)`과 최대 차이는 약 4.44e−16이다. `cycles.V`는 사이클 내 원시 전압 파형으로 길이가 가변적이므로 보간 전압축과 구분한다. 노션의 “2~3.6V” 설명을 이 파일의 `Qdlin` 축에 사용하지 않는다.

원저자 보간 코드도 3.5→2.0V의 1,000점을 만들며, 방전 전류·시간에서 용량을 계산해 spline으로 평가한다. 실패 시 0 벡터를 반환하는 처리도 있다. 따라서 길이 1,000·유한값만으로 곡선 품질이 보장되지는 않는다. [VQlinspace3](https://github.com/chueh-ermon/BMS-autoanalysis/blob/c82ab7704211a6aee75bd926714b82d1f95e1a0e/VQlinspace3.m)

로컬 표본의 `Qdlin`은 원시 방전 곡선 내부와 대체로 근사적으로 일치하지만 끝점은 같지 않았다. 세 파일의 첫·마지막 셀에서 사이클 10·100을 비교한 12개 표본에서 `summary.QDischarge−Qdlin[-1]`은 약 0.01498–0.04989Ah였다. **`Qdlin[-1]`을 총 방전 용량이나 EOL 판정값으로 대체하지 않는다.** EOL 비교는 `summary.QDischarge`의 정의를 사용한다.

단위는 생성 코드와 원본 파형을 함께 확인했다. `cycles.I`는 `Current/1.1`로 저장되어 **정규화 C-rate**이며 A로 표시하려면 `I_A=1.1×I`로 변환한다. 로컬 표본의 일반 방전 평탄부도 약 −4이고 공통 4C 방전과 일치한다. `cycles.t`는 경과 초를 60으로 나눈 **분**, `summary.chargetime`도 분으로 저장된다. 원시 파형의 단위 속성이 없다는 이유로 추정하지 않고 코드 변환을 근거로 삼았다. [cell_analysis 단위 변환](https://github.com/chueh-ermon/BMS-autoanalysis/blob/c82ab7704211a6aee75bd926714b82d1f95e1a0e/cell_analysis.m)

### 3.2 ΔQ100−10(V) 계산과 로그 특징

같은 전압 좌표에서 `ΔQ(V)=Q100(V)−Q10(V)`를 계산한다. 사이클의 리스트 위치와 실제 사이클 번호를 구분하고, `summary.cycle` 또는 원본 사이클 대응을 확인한다. 이 로컬 자료의 summary 번호는 1..N이지만 B1 첫 사이클은 빈 표식이다. [Supplementary Note 1](https://media.springernature.com/original/springer-static/esm/art%3A10.1038%2Fs41560-019-0356-8/MediaObjects/41560_2019_356_MOESM1_ESM.pdf)

보충자료는 별도 언급이 없으면 log를 밑 10으로 정의한다. n개 전압점에서 사용한 두 특징은 다음과 같다.

```text
delta_i = Q100(V_i) - Q10(V_i)
variance_feature = log10( sum((delta_i - mean(delta))^2) / (n - 1) )
minimum_feature  = log10( abs(min(delta)) )
```

분산은 표본분산(`ddof=1`)이다. n=1,000에서 `ddof=0` 대신 1을 쓰면 log10 분산은 모든 셀에서 `log10(1000/999)≈0.00043451`만큼 증가한다. 동일한 점 수를 사용한 유한값끼리 비교한다면 이 상수 이동은 Pearson·Spearman 상관을 바꾸지 않지만, 논문 재현 시 정의를 기록한다. `log10(min(delta))`는 음수에서 정의되지 않으며, `min(log10(abs(delta)))`도 위 정의와 다르다. 분산 0이나 최소값 0이면 로그가 유한하지 않으므로 별도 품질 표시가 필요하다. 임의 epsilon·절댓값·필터를 추가했다면 값과 처리 원칙을 보고하고, 논문과 동일한 특징이라고 표현하지 않는다.

두 벡터에 **동일한** 전압 재정렬을 적용하면 전체 구간 분산·최소값은 그대로다. 그러나 한쪽 곡선만 뒤집거나 원시 `cycles.V`를 `Qdlin`의 좌표로 붙이면 잘못된 차이가 생긴다. 전압 일부를 자를 때는 구간·점 수·보간법이 특징 정의를 바꾸므로 전체 1,000점 특징과 구분한다.

### 3.3 물리 해석의 범위

분산은 전압 구간별 용량 곡선 변화의 비균일성을 요약하고, 최소값은 가장 큰 음의 변화 위치의 크기를 요약한다. 이는 예측에 유용한 통계량이지 특정 열화 기구의 직접 측정값은 아니다. 같은 위치의 값도 전류·휴지·온도·보간에 영향을 받는다. 원 논문은 초기 전체 용량에 드러나지 않는 음극 활성물질 손실 등이 전압 곡선에 나타날 수 있다고 논의하지만, 개별 셀에서 lithium plating·흑연 파괴·SEI 성장을 이 특징 하나로 확정하지 않는다. [원 논문 Results·Discussion](https://web.mit.edu/braatzgroup/Severson_NatureEnergy_2019.pdf)

EDA에서 계산한 유한 라벨 129셀의 log10 분산–수명 Pearson r=−0.8506, Spearman ρ=−0.8921이다. 배치별 r은 B1 −0.8861, B2 −0.9019, B3 −0.7019이며 배치 내 중심화 후 r=−0.7731이다. **이 수치는 기존 EDA 계산값이고 본 도메인 검토에서 독립 재계산한 값은 아니다.** 배치 내에서도 연관성이 관찰된다는 해석은 가능하지만, 인과관계·held-out 예측 성능·물리적 셀 독립성의 증거는 아니다. 수명 NaN 10셀은 정답을 대체하지 않고 곡선 EDA에만 포함한다.

세 파일의 139셀 모두 Q10·Q100의 278곡선은 길이 1,000이며 유한·비영 벡터임을 확인했다. B1의 초기100사이클은 첫 빈 표식 때문에 유효 양의 QD 관측이 셀당99개이고, B2/B3는 셀당100개다. 같은 ‘초기100 평균’이라도 유효 표본 수를 보고해야 한다.

일반적으로 100사이클 이전에 종료된 셀은 이 특징을 계산할 수 없다. 100번째 관측을 채워 넣거나 최종 사이클을 Q100으로 이름 바꾸지 않는다. 적용 대상이 ‘100사이클까지 살아 있고 유효 파형을 확보한 셀’로 제한되는 선택 효과를 명시한다. 현재 세 파일에서 Q10·Q100이 가용하다는 확인과 다른 데이터에 대한 이 일반 조건을 구분한다.

## 4. 초기 용량 증가·knee·IR의 해석

초기에 방전 용량이 조금 증가하는 현상을 이상치나 열화가 없다는 증거로 일괄 해석하지 않는다. 원 논문과 보충자료는 저율 진단·휴지 후의 용량 회복 및 전극 overhang의 영향을 논의한다. **“activation”은 이 EDA에서 관측한 초기 용량 증가의 서술용 표현**으로만 쓰고 특정 물리 기구가 확인된 것처럼 표현하지 않는다. [Supplementary Note 5 및 관련 진단 그림](https://media.springernature.com/original/springer-static/esm/art%3A10.1038%2Fs41560-019-0356-8/MediaObjects/41560_2019_356_MOESM1_ESM.pdf)

Knee는 용량 열화가 빠르게 진행되는 구간의 전환을 뜻하지만 보편적인 단일 수치 정의가 없다. 전체 곡선으로 찾은 사후 knee와 초기 구간에서 예측한 knee를 구분하고, 평활·구간·탐지법을 명시한다. 진단 사이클의 용량 회복, 휴지 변화, 잡음으로 생긴 일시적 꺾임을 그대로 knee로 확정하지 않는다. 여러 내부 기구가 비슷한 용량 궤적을 만들 수 있다. [Attia 등, Knees 리뷰](https://iopscience.iop.org/article/10.1149/1945-7111/ac6d13)

IR은 주어진 SOC·온도·펄스 조건에서 측정한 지표다. 평탄한 IR이나 스파이크 하나로 흑연 음극 구조 특성·셀 교체·특정 열화 원인을 확정할 수 없다. 스파이크는 인접 사이클 파형, 센서 접촉, 휴지·진단 조건, 동시 QD·온도 변화를 대조할 조사 지점이다. 비교적 작은 Pearson r은 해당 평균·구간에서 선형 연관성이 약하다는 뜻이며, 모든 비선형·조건부 연관성이 없다는 뜻은 아니다. 원 논문의 IR 측정 조건은 충전 중 80% SOC에서의 펄스 측정이다. [원 논문 Methods](https://web.mit.edu/braatzgroup/Severson_NatureEnergy_2019.pdf)

## 6. EDA에서 모델링으로 넘어갈 때의 제한

- 한 행은 한 셀의 초기 구간 특징이어야 한다. 같은 셀의 수천 사이클 행을 독립 학습·검증 표본으로 나누지 않는다. 파일 내 cell_id와 물리적 셀의 동일성은 별도 문제다.
- 전체139셀/유한129셀의 탐색 상관을 보고하되, 최종 테스트 배치의 결과로 특징·전처리를 골라 다시 그 배치를 최종 평가하면 선택 누수가 생긴다. 스케일링·결측 대치·선택은 학습 구간에서만 적합한다.
- “장수명 >1,000 / 단수명 <500”은 EDA 구간이다. 노션의 binary classification 기준550과 섞지 않는다. 500~1,000 중간 구간의 비율도 함께 보고한다.
- early100 평균은 첫 zero/빈 표식·실패 벡터·유효 사이클 수를 확인해야 한다. 사이클을 삭제했다면 10·100 같은 실제 번호를 다시 붙이지 않는다.
- `charging_policy` 정적 라벨만으로 변형·진단 스케줄의 전 생애 전류·휴지 조건을 대표하지 않는다. 고속 방전과 저율 진단 사이클의 Q(V) 차이를 열화만으로 해석하지 않는다.
- B2의 NaN 8셀과 B3의 NaN 2셀은 수명 회귀·분류의 정답으로 쓰지 않는다. 관측 길이로 수명을 채우지 않고 미라벨 셀의 정책·파형·종료 상태는 품질 EDA에서 보고한다.
- B1/B3의 유한 라벨과 파일 내 임계값 이벤트 여부를 구분한다. 관측 미도달 셀의 최종 용량·관측 길이·원문 라벨을 보존해 민감도 분석의 조건을 명시한다.
- 연구 대상은 실험실 고출력 LFP/graphite 셀이다. 이 모델의 사이클 수를 ESS 운영 연수·교체 비용·현장 안전성으로 직접 변환하려면 운전 조건·calendar aging·팩 불균일성 등의 별도 자료가 필요하다.
