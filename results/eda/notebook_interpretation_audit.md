# 노트북 해석 검토 및 데이터 QA

검토 대상: `30-ESSHealth-scratch.ipynb`의 코드, Markdown, 저장 출력과 그림 6개. 최신 노트북은 39개 셀이며, 새 ΔQ(V) 절은 셀 24~27에 있다. IR·정책·상관 해석의 셀 번호는 추가된 4개 셀을 반영했다.

검토일: 2026-10-01. 원본 노트북은 수정하지 않았다. 아래 셀 번호는 notebook JSON의 **0-based 인덱스**이다.

## 검토 범위와 데이터 상태

기존 노트북의 출력은 **2017-05-12 Batch 1의 46개 셀**에 대한 결과이다. 분석 대상 분석 범위는 **B1=2017-05-12, B2=2018-02-20, B3=2018-04-12의 3개 배치**이다. 이 범위로 확장하면 기존 숫자와 해석을 그대로 재사용하면 안 된다. 다음은 지정한 3개 배치의 원자료 상태이다.

| 배치 | 날짜 | 원자료 셀 수 | 유한한 `cycle_life` 수 | 유한하지 않은 `cycle_life` 수 |
|---|---|---:|---:|---:|
| B1 | 2017-05-12 | 46 | 46 | 0 |
| B2 | 2018-02-20 | 47 | 39 | 8 |
| B3 | 2018-04-12 | 46 | 44 | 2 |
| 합계 | — | 139 | 129 | 10 |

초기 100사이클의 ΔQ 계산에 필요한 자료는 분석 대상 원자료 **139개 셀 모두**에서 확인되었다. **초기 특징의 가용성과 수명 라벨의 가용성은 별개**이다. 라벨이 유한한 129개 셀도 물리 셀 중복, 후속 실험, EOL 라벨 QC를 검토하기 전에는 독립적인 학습 표본 수로 확정하지 않는다. 라벨이 유한하지 않은 셀은 B2의 8개와 B3의 2개, 총 10개이다.

`barcode`는 HDF5에서 길이 6의 `uint32` MATLAB string object로 저장되어 있으며 실제 물리 셀 ID로 해독되지 않았다. 이 배열의 일치, `mat73` 변환 후의 `None`, 혹은 배치 내 위치 인덱스의 일치만으로 동일한 물리 셀이라고 판단하면 안 된다. 물리 셀 연결은 공식 대응표 또는 검증 가능한 별도 근거가 필요하다.

## 새 ΔQ(V) 절 검토

최신 셀 24~27에는 ΔQ 추출 함수·그림·해석이 구현되어 있다. 새 함수는 노트북에서 로드한 **Batch 1**을 입력으로 사용하며, 별도 스크립트의 지정 3개 배치 EDA와 범위가 다르다.

- 방향은 `Q100(V) - Q10(V)`이고, 0 아래의 값은 해당 전압에서 100번째 사이클의 누적 방전 용량이 10번째보다 작다는 뜻이다. 이를 특정 전기화학 기전의 증거로 해석하지 않는다.
- 원자료 B1 46개 셀의 `summary['cycle']`을 직접 확인했으며, 모두 Python 위치 9가 실제 cycle 10, 위치 99가 실제 cycle 100이었다. 비어 있는 첫 사이클을 삭제하지 않는 현재 99−9 정렬은 B1에서 맞다. 새 함수 자체는 실제 cycle 번호를 읽지 않으므로 다른 형식의 데이터에 재사용할 때는 원자료 cycle 번호와의 대응을 검증해야 한다.
- 새 함수는 dict-of-lists와 list-of-dicts를 처리하고, Qdlin 존재 여부·전압/용량 길이·유한성을 검사한다. 그림 색상은 `cycle_life` 값에 직접 연결되며, `coolwarm_r`를 사용해 짧은 수명을 빨강, 긴 수명을 파랑으로 표시한다. 기존 QD 그림의 cell_id 순서 색상과 구분해야 한다.
- 새 함수는 `cycle_life`가 NaN/Inf인 셀을 `skipped`로 보내며 ΔQ 그림에서도 제외한다. 따라서 다른 배치에 적용하면 곡선이 가용해도 수명 라벨이 없는 셀은 그려지지 않는다. 별도 3개 배치 스크립트에서 이들을 회색으로 표시하는 동작과 다르다.
- 새 함수에는 분산 특징이나 수명 모델 학습이 아직 없다. 분산·최솟값의 후보 특징 제안은 가능하지만 예측 성능이 확인된 것은 아니다. 100사이클 ΔQ 특징을 5사이클 시점의 예측에 사용하면 안 된다.

## 추가 코드·통계 주의사항

- `extract_summary()`는 원자료의 `summary['cycle']`을 사용하지 않고 위치 `c+1`을 사이클 번호로 생성한다. 실험 사이클의 누락·중복·시작 번호를 먼저 확인해야 한다.
- `df.describe()`의 `cycle_life` 평균 **884.241**은 38,811개의 사이클 행에 같은 라벨을 반복한 결과이다. 셀당 한 표본으로 계산한 평균 **844.7**과 구분해야 한다.
- `df.isnull().sum()==0`은 결측 없음의 충분한 근거가 아니다. 저장 출력의 첫 행은 QD·QC·IR·온도·충전시간이 모두 zero이며, 첫 상세 cycle의 변수는 `None`이다.
- 초기 10/100사이클 집계는 `df_clean`이 아닌 raw `df`를 사용한다. 초기 placeholder와 스파이크에 대한 QC가 적용되지 않았다.
- 모든 셀에 동일한 개수의 zero가 같은 창 길이로 포함된다면 평균에 공통 배율만 적용되어 Pearson r이 그대로일 수 있다. zero 제거로 상관이 반드시 바뀐다는 주장도 피하고 실제 QC 전후 값을 비교해야 한다.
- 초기 10행 평균 IR의 r=0.088과 초기 100행 평균 IR의 r=0.177은 서로 다른 집계 결과이다. 동일한 특징의 상반된 결과로 해석하지 않는다.
- `mat73` 저장 출력은 지원하지 않는 MATLAB string 타입을 보고했고 `barcode`·`channel_id`는 `None`이었다. summary에서 NaN이 발견되지 않았다는 이유로 메타데이터까지 온전하게 로드됐다고 판단하면 안 된다.
- 기존 `int(cell['cycle_life'])` 변환은 유한 라벨만 있는 B1에서는 실행됐지만, 유한하지 않은 라벨이 존재하는 전체 archive에 동일 적용하면 실패할 수 있다. 라벨 상태를 먼저 보존하고 검사해야 한다.
- 현재 모델 구현이 없어 실제 학습·평가 누수를 확정할 수는 없다. 지정한 3개 배치 통합 시 물리적으로 같은 셀의 후속 실험을 서로 다른 학습·평가 표본으로 나누는 위험을 확인해야 한다.
- 전체 생애 곡선을 EDA에서 표시하는 것은 그 자체로 누수가 아니다. 미래 cycle, 종료 여부, 라벨에서 도출한 정보가 초기 예측 특징 또는 학습 전에 수행하는 전처리에 유입되는지를 구분해 검사해야 한다.

## QA 체크리스트

| 영역 | 확인 항목 |
|---|---|
| 셀 단위 집계 | `batch_id + source_index`를 보존하고 물리 셀 식별자를 별도로 둔다. 셀별 1개 라벨·1개 특징 행으로 통계와 모델링을 수행한다. 원자료 배열의 barcode 일치만으로 셀을 병합하지 않는다. |
| 구조·사이클 정렬 | summary 각 필드 길이, 원자료 cycle 번호의 단조성·중복·누락, 상세 cycles와 summary의 매핑을 검사한다. 위치 인덱스를 실험 cycle 번호로 가정하지 않는다. |
| 결측·placeholder | NaN/Inf와 zero를 별도로 집계한다. 초기의 모든 지표 zero 행, 비어 있는 상세 cycle, 메타데이터 디코딩 실패를 분리해 기록한다. |
| IR zero | zero·비유한 값을 별도 flag로 집계하고 배치·셀·사이클별 위치를 제시한다. IR zero만 있다는 이유로 다른 유효 변수까지 행 전체를 제거하지 않는다. |
| 초기 100사이클 가용성 | 지정한 3개 배치의 초기 100 ΔQ 자료는 원자료 139개 셀 모두에서 확인됐다. 향후에도 행 100개와 cycle 100 존재를 구분하고, 특징별 유효 사이클 수와 실제 cycle 10/100의 Qdlin을 점검한다. |
| EOL 라벨 QC | 제공 `cycle_life`, 관측 최종 cycle, 기준 용량, 첫 유효 임계값 교차 cycle을 함께 기록한다. zero placeholder는 교차에서 제외한다. 관측 종료·임계값 미도달·배치 간 계속 실험을 구분한다. NaN/Inf 라벨을 임의로 종료 cycle로 치환하지 않는다. |
| QD 필터 | 임계값 이하의 관측을 EOL 검증 전에 제거하지 않는다. 그림용 QC 제외와 향후 학습용 처리 규칙을 구분해 명시한다. |
| 공통 전압 grid | 셀별 `Vdlin`의 길이·유한성·단조성·전압 범위를 검사한다. Qdlin 길이가 같다는 이유로 동일 전압 좌표라고 가정하지 않는다. |
| ΔQ(V) | 실제 cycle 10/100을 매핑하고 동일 V grid에서 `Q100(V)-Q10(V)` 방향을 명시한다. 필요하면 공통 겹침 범위에서 보간하고 외삽은 피한다. 분산의 log를 사용할 때 zero·비유한 값을 별도 처리한다. |
| 상관계수 | 배터리 단위 집계와 변수별 유효 표본 수를 명시한다. Pearson·Spearman, QC 전후 민감도, 배치별 결과를 비교하고 상관을 인과로 표현하지 않는다. |
| 정책 비교 | 정책별 n과 분포를 제시한다. 평균으로 정렬한 순위를 C-rate 자체의 단조 관계로 해석하지 않는다. ±표준편차와 평균의 불확실성을 구분한다. |
| 향후 학습·평가 | 물리 셀/후속 실험 단위로 분리한다. 미래 cycle과 종료 관련 정보가 특징에 들어가지 않도록 하며, 배치별 평가와 전처리의 학습 fold 적합 여부를 확인한다. |

## 향후 모델링 설계에서 결정할 항목

이번 검토의 범위는 archive EDA의 근거 확인과 기존 노트북 해석 정리이다. 아래는 **현재 확정할 요구사항이 아니라 향후 모델링에 들어갈 때 추가 검토할 항목**이다.

- 지정한 3개 배치의 후속 실험을 병합할지, 그때 어떤 검증 가능한 물리 셀 대응 근거를 사용할지.
- 제공 수명 라벨과 재계산 EOL 중 어느 것을 목표값으로 사용할지, 기준 용량·임계값·관측 종료 처리를 어떻게 정의할지.
- 미래 데이터에서 초기 100사이클 자료가 부족한 셀을 어떻게 다룰지. 지정한 3개 배치의 초기 ΔQ는 139개 셀 모두에서 가용하지만 수명 라벨은 10개가 유한하지 않다.
- 이진 분류의 장·단수명 기준을 어떻게 정의할지.
- 동일 조건 내 예측과 새 배치·새 충전 정책으로의 일반화 중 어느 평가 목적을 우선할지.

전기화학 기전은 원자료 코드·그래프만으로 특정하지 않았다. 정책의 실제 충전 프로토콜과 기전 설명을 추가할 경우 공식 실험 문서나 검증 가능한 근거를 별도로 연결해야 한다.
