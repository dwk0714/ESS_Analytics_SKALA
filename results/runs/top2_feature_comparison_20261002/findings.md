# 상관 상위 두 변수 추가 비교

IR을 제외한 후보9개에서 B1 train35의 실제 cycle_life와 절댓값 Pearson 상관이 가장 큰 두 변수는 ΔQ 하위5% 분위수(r=0.8818005)와 전체 ΔQ 평균(r=0.8467517)이다. 두 변수끼리 상관은r=0.993205으로 높다. 모델 입력은 기존 ΔQ(V) log분산과 충전 RMS전류에 이 두 변수를 추가한4변수이며, 앙상블의 OLS 기반모델은 기존 ΔQ log분산1개에 추가하여3변수다.

변수 순위는 전체 B1 train35에서 한 번 정해 outer 평가에 재사용하지 않았다. 매 outer 학습 fold, 튜닝 inner 학습 fold, stacking meta OOF 학습부분에서 해당 학습자료만으로 다시 계산했다. outer15개에서는 두 변수가 모두15/15회 선택됐다. 더 작은 inner/meta 학습부분에서는 충전시간·온도·용량추세가 일부 선택됐다. 마지막35셀 적합 단계에서 두 변수를 다시 확정하고, 모든 모델/설정을 저장한 후에만 holdout/B2/B3를 평가했다.

## 동일 조건의 비교

- 기존 고정 B1 train35/holdout11/B2 39/B3 44를 유지했다.
- 반복 정책 그룹 outer5fold×3회(seeds42,7,2026), inner3fold, log10 수명 목표를 사용했다.
- Ridge와 stacking meta Ridge는alpha1 고정이다. CatBoost와 XGB는깊이1..3의 동일12개 설정을 탐색했다.
- XGB와 CatBoost의 기존 입력은2변수에 고정했다. 과거1/2/3변수까지 고르던 실험과 baseline 수치가 다를 수 있다.
- Voting은OLS/Ridge/XGB의 원 수명 단위 예측을 동일 가중 평균한다. Stacking은 정책 그룹 OOF log10 예측으로 학습하며, 각 meta 학습부분의 변수 선택과 XGB 튜닝도 독립 수행했다. 과거 meta OOF의 전체 학습부분에서 정한 XGB 설정을 공통 사용하던 절차와 다르다.

|모델|기존 nested MAPE|두 변수 추가|차이(%p)|반복 개선 횟수|Holdout 기존→추가|
|---|---:|---:|---:|---:|---:|
|Ridge alpha1|7.1018%|6.9119%|−0.1899|2/3|16.1535→14.0839%|
|CatBoost|8.1781%|8.1513%|−0.0268|1/3|5.1082→5.5362%|
|Voting|6.6499%|6.4520%|−0.1979|2/3|12.7444→9.9558%|
|Stacking|6.8897%|6.6450%|−0.2447|3/3|14.3010→11.3846%|

Stacking의 반복별 추가 효과는−0.2811,−0.3279,−0.1251%p이며 holdout도 같은 방향이다. 이번표에서3회와 holdout이 모두 개선된 쌍은Stacking뿐이다. 평균 개선0.2447%p는 작은 값이며, 반복 간 자료는 겹치므로3회를 독립 표본이나 통계적 유의성 검정으로 해석하지 않는다. 높은 단변량 상관과 변수 선택 안정성은 추가 예측 정보의 크기를 보장하지 않는다. 연구 후보 중 nested 평균이 가장 낮은 모델은추가 Voting6.4520%지만, 동일모델 기준 추가효과는반복1회에서악화했다.

## 단독 ΔQ log분산 모델과 절충

|모델|nested CV|B1 holdout|B2|B3|
|---|---:|---:|---:|---:|
|OLS ΔQ log분산 단독|7.5100%|18.2027%|28.8637%|12.5949%|
|두 변수 추가 Ridge|6.9119%|14.0839%|31.5058%|13.3425%|
|두 변수 추가 Voting|6.4520%|9.9558%|30.2746%|13.3372%|
|두 변수 추가 Stacking|6.6450%|11.3846%|27.7167%|12.7800%|

단독모델은 간단하고 이 비교의B3 오차가 가장 낮다. B1 CV와 holdout은 추가 앙상블보다 높다. B2에서는추가 Stacking이 단독보다1.1470%p 낮고 B3에서는단독이0.1851%p 낮다. 따라서단독을 모든조건에서 최고라고 판단할 수는 없다. 두변수 추가가 모든모델에서 일관되게 개선되는 것도 아니다. 최종 모델 교체는 보류했으며 기존 모델·설정·보고서는 유지했다.

## 검증과 한계

원본과 이전 실험252개 파일의 SHA256을 실행 전후 비교해 보존을 확인했다. OLS 단독과 Ridge baseline/+top2의 repeated CV 숫자는 별도 검산과 일치했다.9개 저장 모델을 독립 프로세스에서 읽어 외부 예측846행을 재현했다. 후보 선택/튜닝/meta OOF의 학습셀은 고정 train35의 부분집합이며 정책 그룹이 분리돼 있다. 모든 신규 후보는 cycle100까지의 기존 탐색 변수이고, 수명 종료나 미래 용량을 입력에 쓰지 않았다.

35셀 개발표·11셀 holdout의 작은 표본이고, B2/B3는 앞선EDA와 실험에서 이미 관찰됐다. 제공 수명 정답과 센서/곡선 QC 문제는 그대로 유지했다. 외부 점수는설정 확정 이후 보고했으며 후보나 모델 선택에 이용하지 않았다. 검증 스크립트는/private/tmp에만 두고 제출하지 않았다.
